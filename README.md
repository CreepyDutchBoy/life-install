# Life — install

Install page, installer/uninstaller and the portable AppImage for **Life** (Conway's Game of Life bench, Rust + Slint + LuaJIT).

**Current version: 0.1 beta (Linux x86_64)**. See [Releases](https://github.com/CreepyDutchBoy/life-install/releases) for every version.

```sh
curl -fsSL https://creepydutchboy.github.io/life-install/install.sh | sh
```

Page: https://creepydutchboy.github.io/life-install/
